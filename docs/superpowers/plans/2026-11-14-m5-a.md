# M5-A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** classic 호환성을 유지하며 minimal/bold와 대비 보정 이력을 제공한다.
**Architecture:** core/themes.py가 검증·토큰·대비를 담당하고 기존 render/editor/workflow가 테마를 전달한다. 공유 HTML을 유지한다.
**Tech Stack:** Python 3.12, Pydantic, Jinja2, Streamlit, Playwright, Pillow.
**Spec:** ../specs/2026-11-14-m5-a-design.md (사용자 승인 및 추가 조건 반영).

## Global Constraints

- #305b46 및 대비 충족 classic은 픽셀 동일. 부족한 색은 글자·강조색만 보정.
- contrast_adjustments는 원래 값·보정 값·대비 비율을 기록. 성공한 보정은 검수 항목 아님.
- 과거 스냅샷 보존. 외부 URL·@import·새 폰트 금지. 기본 classic.
- 전체 테스트 후 A 단일 커밋·푸시. 설계·계획 문서 함께 커밋.

## Review Focus

- CSS 주석·대소문자·이스케이프를 이용한 외부 참조는 거부한다.
- theme 생략 시 기존 작업 설정을 보존한다.
- 테마 변경 후 오래된 스냅샷을 다운로드·승인하지 않는다.
- 승인 후 재개와 재생성에도 theme을 보존한다.
- classic 기준 픽셀 비교는 동일 브라우저에서 기존 CSS로 렌더한 결과와 비교한다.
