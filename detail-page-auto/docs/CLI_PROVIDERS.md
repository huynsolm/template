# 선택 기능: 구독 CLI로 문구 받기

기본 방식은 채팅에 프롬프트를 붙여넣고 답변 파일을 저장하는 방식입니다. 선택 기능인 CLI 방식은 사용자가 이미 로그인한 공식 CLI를 실행합니다. 유료 API 키와 API SDK를 사용하지 않습니다. 구독제 사용량 한도가 적용되며, 개인 사용 범위에서 사용하고 각 서비스 약관을 확인하세요.

## 확인한 환경과 기본 명령

2026-11-13에 `/opt/codex/bin/codex --version`과 `codex exec --help`를 확인했습니다. 버전은 **codex-cli 0.167.0-alpha.4**입니다. `codex login status` 결과는 **Logged in using ChatGPT**였습니다. 이 확인 과정에서 실제 모델 생성 요청은 하지 않았습니다. 자동 테스트는 실제 서비스를 호출하지 않고 임시 Python 스크립트만 실행합니다.

기본 `providers.toml`의 Codex 인자 목록은 다음 명령에 해당합니다.

```text
codex exec --sandbox read-only --ephemeral --skip-git-repo-check --ignore-user-config --output-last-message {answer_file} -
```

확인한 도움말에 따른 옵션 의미:

| 인자 | 용도 |
| --- | --- |
| `exec` | 비대화형 실행 |
| `--sandbox read-only` | 모델이 생성하는 명령에 읽기 전용 샌드박스 적용 |
| `--ephemeral` | 세션 파일을 디스크에 영구 보관하지 않음 |
| `--skip-git-repo-check` | 빈 임시 디렉터리에서 실행 허용 |
| `--ignore-user-config` | 사용자 `config.toml`을 불러오지 않음. 인증은 기존 `CODEX_HOME` 사용 |
| `--output-last-message FILE` | 진행 로그와 구분해 마지막 답변을 파일로 받음 |
| `-` | 표준 입력으로 프롬프트 전달 |

읽기 전용 샌드박스는 명령 실행 자체를 완전히 비활성화하는 옵션은 아닙니다. CLI는 비어 있는 임시 디렉터리에서 실행됩니다. 승인·샌드박스 우회 옵션은 사용하지 않습니다. 새 버전을 설치했다면 해당 버전의 `exec --help`를 다시 확인하세요.

Claude Code(`claude`)와 Gemini CLI(`gemini`)는 이 환경에 설치되어 있지 않아 버전과 옵션을 확인하지 못했습니다. 따라서 기본 설정은 `configured = false`이며 실행하면 설정이 필요하다는 오류를 냅니다. 검증하지 않은 플래그를 제공하지 않습니다. 바로 사용하려면 붙여넣기 방식을 사용하세요.

## 설정 변경

`detail-page-auto/providers.toml`에서 명령을 인자 배열로 지정합니다. 설치한 공식 CLI의 `--help`에서 비대화형 실행, 표준 입력 수신, 읽기 전용·도구 비활성 옵션을 확인한 뒤 설정하세요. CLI에 해당 권한 제한 옵션이 있으면 반드시 포함하세요. Claude/Gemini 설정 시 `configured = false` 줄을 지우고 `command = [...]`를 지정합니다.

```toml
[providers.codex]
command = ["codex", "exec", "--sandbox", "read-only", "--ephemeral", "--skip-git-repo-check", "--ignore-user-config", "--output-last-message", "{answer_file}", "-"]
```

명령은 신뢰할 수 있는 로컬 설정이어야 합니다. 토큰이나 로그인 설정 내용을 이 파일에 넣지 마세요. 로그인은 각 공식 CLI의 자체 로그인 명령으로 미리 완료합니다. 실행 파일은 `PATH`에서 찾거나 절대 경로로 지정할 수 있습니다. 작업 디렉터리가 매번 바뀌므로 상대 경로의 실행 파일·스크립트는 사용하지 마세요.

구독 로그인만 사용하도록, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `GOOGLE_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `CODEX_API_KEY` 중 하나라도 비어 있지 않으면 CLI를 실행하기 전에 종료 코드 `6`으로 중단합니다. 해당 환경 변수를 해제하고 공식 CLI의 구독 로그인으로 다시 시도하세요. 변수 값은 오류나 로그에 표시하지 않습니다. `CODEX_ACCESS_TOKEN` 같은 구독 OAuth 변수는 이 검사로 제거하거나 차단하지 않습니다.

이 검사는 알려진 API 인증 환경 변수에 대한 차단입니다. 사용자 지정 명령·래퍼나 CLI 내부 설정의 인증 방식을 검사하지는 않습니다. 사용자 지정 CLI도 반드시 구독 로그인을 사용해야 하며, API 키·API 토큰 설정이나 API 인증 플래그를 추가하면 안 됩니다.

프롬프트는 항상 표준 입력에 UTF-8로 전달됩니다. 셸을 사용하지 않으므로 `$HOME`, 백틱, 따옴표는 실행되지 않고 그대로 전달됩니다. 인자 전체가 정확히 `{answer_file}`일 때만 임시 답변 경로로 바꿉니다. `prefix-{answer_file}` 같은 부분 문자열, 환경 변수, 다른 중괄호는 확장하지 않습니다. 이 표식이 있으면 해당 파일만 답변으로 읽고, 없으면 표준 출력을 답변으로 읽습니다. 후자의 경우 진행 로그가 표준 출력에 섞이지 않도록 공식 CLI의 출력 옵션을 확인하세요.

## 오류와 재시도

기본 제한 시간은 300초입니다. 공급자 어댑터는 한 번만 실행하며, 답변 검증과 수정 프롬프트를 이용한 재시도는 상위 작업 흐름에서 제한합니다(기본 전체 3회). 붙여넣기 공급자는 답변 파일을 읽기만 합니다. 공급자는 문구를 자르거나 고치지 않습니다.

| 종료 코드 | 의미와 조치 |
| --- | --- |
| `3` | CLI가 없거나 공급자 설정이 필요함. 설치·설정을 확인하거나 붙여넣기 방식 사용 |
| `4` | 제한 시간 초과 |
| `5` | 사용량·호출 한도 감지. 붙여넣기 방식으로 전환 |
| `6` | 로그인 필요 또는 API 인증 환경 변수 감지. API 인증 변수를 해제하고 공식 CLI의 구독 로그인 사용 |
| `7` | 다른 실행 오류, 비어 있는 답변, 설정 오류, 읽을 수 없는 답변 파일 |

로그인·한도 분류는 CLI 출력의 일반적인 오류 표현을 확인하는 보조 수단입니다. CLI 버전·언어에 따라 다른 표현은 일반 오류가 될 수 있습니다. CLI의 표준 오류와 설정·인증 값은 프로그램 오류 메시지에 포함하지 않습니다. CLI 출력은 오류 분류를 위해 메모리에서만 확인하며 임시 실행 디렉터리는 호출 후 삭제합니다.
