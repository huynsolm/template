# 분위기 이미지 생성 요청 (image_mood_v1)

## 반드시 지킬 것
- **상품 자체를 그리지 마세요.** 상품이 놓일 공간, 사용 환경, 손이나 소품만 보여 주세요.
- 글자·로고·가격·숫자·상표를 넣지 마세요. 사람 얼굴을 크게 보여 주지 마세요.
- 실제 효과나 성능을 보여 주는 장면(전후 비교, 수치, 인증 마크)을 만들지 마세요.
- 가로 1720px 이상, 가로세로 비율 4:3으로 만들어 주세요.
- 색감은 브랜드 색 {brand_color} 계열과 어울리게 해 주세요.
